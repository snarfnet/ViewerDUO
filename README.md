# Viewer DUO

Realistic page-curl book viewer for iPhone, iPad and iPhone Duo.

- Formats: PDF, EPUB, TXT, ZIP/CBZ, RAR/CBR
- Metal page curl (cylinder deformation, dynamic shadow, backside show-through, page-thickness stack)
- Single page / two-page spread (auto by size class; hinge becomes the spine on iPhone Duo)
- Text engine: CoreText pagination, vertical writing, 5 typefaces, size / leading / margins, Aozora ruby cleanup
- 6 desks x 6 papers, warm filter, bookmarks, table of contents, full-text search, zoom
- Japanese / English

Build: `xcodegen generate` then open `ViewerDUO.xcodeproj` (Xcode 26+, iOS 17+). CI builds and uploads via GitHub Actions.
